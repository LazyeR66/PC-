==============================================
  手柄映射器 - 使用说明
  Xbox 兼容手柄 / 索尼 DSE 手柄 (DirectInput)
  按键 -> 键盘按键映射工具
==============================================

【一、环境要求】
- Windows 10 / 11 系统（自带 .NET Framework 4.x，无需安装任何运行环境）
- 无需安装 Python，无需安装任何第三方包
- 支持 XInput 的 Xbox 兼容手柄（Xbox 手柄、多数第三方手柄、部分国产手柄需切换为 XInput 模式）
- 支持 DirectInput 的索尼手柄：DualSense Edge (DSE) / DualSense / DualShock 4，以及其它
  DirectInput 手柄（北通、飞智、八位堂等原生 DirectInput 模式）
- 已实测：索尼 DualSense Edge 通过 USB 线连接（DirectInput 模式）可被自动识别并正常映射
- 本程序使用系统自带组件（xinput1_4.dll / dinput8.dll），为独立 exe 程序

【二、启动方法】
1. 直接双击 手柄映射器.exe 即可（单文件程序，interception.dll 已内置，无需其它文件）
2. 首次启动自动加载默认配置；若同目录有 config.json 则自动加载其中保存的映射与阈值

【三、选择手柄输入源】
- 程序顶部提供 "手柄输入源" 下拉框，启动后默认 "自动检测 (推荐)"：
  - 自动检测：优先使用 XInput 读取已连接的 Xbox 兼容手柄；若未检测到 XInput 手柄，
    则自动切换为 DirectInput 读取枚举到的手柄（索尼 DSE / DualSense / DS4 等排在列表最前）
  - Xbox 手柄 (XInput)：强制使用 XInput，仅识别 Xbox 兼容手柄
  - DirectInput 设备：下拉框会列出当前已枚举到的 DirectInput 手柄，可手动指定使用哪一只
- 点击右侧 "刷新" 按钮可重新枚举手柄设备（例如插入 / 拔出手柄后）
- 连接索尼手柄提示：
  1) 索尼手柄（DualSense / DS4 / DSE）使用 USB 线连接时默认即为 DirectInput 模式，可直接使用；
  2) 蓝牙连接时 Windows 可能将手柄识别为 XInput（显示为 "Wireless Controller"），
     若需强制使用 DirectInput 请改用 USB 连接；
  3) 程序状态栏会显示当前实际使用的输入源与设备名称（如 "DirectInput: Wireless Controller"）；
  4) 插入 / 拔出 / 切换手柄模式后，点击右侧 "刷新" 重新枚举，程序会自动回退到可用的输入源

【四、配置映射】
1. 在左侧列表点击要配置的手柄输入（如 "A 键"、"十字键 ↑"、"左摇杆 ↑"）
   也可点击右侧 "捕获手柄按键" 按钮，然后按下手柄上想要配置的按键，程序会自动选中对应项
2. 在右侧 "映射为键盘按键" 下拉框中选择目标键盘按键（如 W、空格、方向键等）
3. 点击 "设置映射" 完成该项配置；"清除映射" 表示该项不转发
4. 可调整 "摇杆触发阈值" 与 "扳机触发阈值"（摇杆推得越深、扳机按得越重越容易触发）
5. 点击 "保存配置" 持久化到 config.json（下次启动自动加载），或 "加载配置" 读取其它配置

【五、开始使用】
1. 点击顶部 "开始映射" 按钮，程序开始将手柄输入转发为键盘按键
2. 点击 "停止映射" 或直接关闭窗口，程序停止并释放所有按键

【六、可映射的手柄输入】
- 按键：A / B / X / Y、LB / RB、LT / RT（扳机）、Back、Start、左摇杆按下(L3)、右摇杆按下(R3)
- 索尼手柄特有按键：PS 键、触摸板点击(TOUCHPAD)
- 十字键：上 / 下 / 左 / 右（含斜向）
- 摇杆方向：左摇杆 上/下/左/右、右摇杆 上/下/左/右
- 扳机：LT / RT（DirectInput 下按轴读数触发，支持轻重程度调节阈值）

【七、可映射的键盘按键】
- 字母 A-Z、数字 0-9
- F1-F12、方向键、空格、回车、Esc、Tab、退格、Delete、Insert、Home、End、PageUp、PageDown
- Shift、Ctrl、Alt、CapsLock 及常用标点符号

【八、常见问题】
Q: 手柄按了没反应？
A: 1) 确认程序顶部显示 "已连接" 且输入源正确（索尼手柄应显示 DirectInput 设备名）；
   2) 确认已点击 "开始映射"；3) 确认该项已设置映射（列表显示按键名而非"无"）。

Q: 索尼 DSE / DualSense 手柄连接后无反应？
A: 1) 优先使用 USB 线连接（蓝牙可能被识别为 XInput "Wireless Controller"）；
   2) 在顶部 "手柄输入源" 下拉框点击 "刷新"，确认列表中出现 DirectInput 设备并选中；
   3) 若仍无反应，请在 Windows 游戏控制器设置中确认手柄已被系统识别；
   4) 部分索尼手柄需按 PS 键开机或进入 USB 有线模式后才会被系统枚举到。

Q: 如何自检程序是否读得到手柄？
A: 打开 cmd / PowerShell，执行：手柄映射器.exe --selftest
   程序会在 %TEMP%\gm_selftest_log.txt 写入诊断日志，包含：
   - 枚举到的 DirectInput 手柄数量与设备名 / GUID / 设备类型
   - CreateDevice / Acquire / GetState 是否成功
   - 若设备打开成功，会提示"请按下手柄任意按键"，10 秒内按下任意键并拨动摇杆，
     日志显示 "检测到状态变化，读取正常" 即代表读取链路完整可用。

Q: DirectInput 枚举不到索尼手柄？
A: 1) 确认手柄已通过 USB 线连接且系统已识别（"设备管理器 -> 人机接口设备 -> HID-compliant game controller"）；
   2) 运行 --selftest 查看 DirectInput devices 数量是否为 0（0 表示系统内确实没有手柄在枚举列表中）；
   3) 若手柄显示为 "Wireless Controller" 且以蓝牙连接，请改用 USB 线连接。

Q: 摇杆方向总是误触发？
A: 增大 "摇杆触发阈值"（默认 16000）。

Q: 程序启动报错 / 无反应？
A: 1) 确认已双击 手柄映射器.exe（独立程序，无需 Python、无需其它文件）；
   2) 查看系统是否已安装 .NET Framework 4.x（Win10/11 默认自带）。

Q: 国产手柄不被识别？
A: 确认手柄处于 XInput 模式（部分手柄需长按某键或使用厂商软件切换为 Xbox/360 模式）；
   若手柄支持原生 DirectInput 模式，也可在输入源中选择对应 DirectInput 设备。
【九、驱动级注入（解决游戏内按键无效，推荐）】
很多游戏（如 Apex 英雄）不读 Windows 消息队列，而是用 RawInput/DirectInput 直接读
硬件键盘队列，SendInput 模拟的按键会被无视。要穿透它，必须用驱动级注入——把按键
注入到键盘驱动栈，游戏看到的就是真实硬件事件（Xtoplay 内置 DD 驱动就是这个原理）。
本程序已集成开源的 Interception 驱动方案，按以下步骤一次配置永久生效：

第一步：安装 Interception 驱动（只需一次）
  1. 打开文件夹：driver\Interception\command line installer\
  2. 右键 install-interception.exe -> 以管理员身份运行
  3. 按提示完成安装，然后重启电脑
  （驱动为非商业用途 LGPL 3.0 开源许可，详见 driver\Interception\licenses 目录；
    日后想卸载：同目录右键 uninstall-interception.exe 以管理员运行，再重启）

第二步：确认 DLL 就位
  interception.dll 已作为嵌入资源内置进 手柄映射器.exe（单文件自包含）。
  程序首次使用驱动注入时会自动把它释放到 exe 同目录，无需手动放置。

第三步：编译并启动（普通用户可跳过，直接用现成 exe）
  1. 如需自行改源码重新编译：进入 "源码" 子文件夹，双击 重新编译.bat，
     会在上级目录生成新的 手柄映射器.exe（编译前自动备份旧版到 源码\backup\）
  2. 启动 手柄映射器.exe，点击"开始映射"
  3. 看状态栏：显示"映射运行中…（驱动级注入）"即驱动生效；
     若显示"驱动不可用→已回退扫描码"，说明驱动没装好，回到第一步检查

第四步：进游戏测试
  按手柄按键，游戏内对应键盘功能应能触发（如 Apex 按 Back 键 = 开麦）。
  注意：驱动注入和真实键盘一样，只发送给当前前台窗口，玩游戏时游戏必须是焦点窗口。

【十、注入模式切换（高级）】
config.json 中的 "inject_mode" 控制按键发送方式：
- "driver"（默认）：Interception 驱动级注入，游戏兼容性最好；
  驱动/DLL 缺失时自动回退扫描码，再回退虚拟键，不会卡不会崩；
- "scan"：扫描码注入（SendInput + 硬件扫描码），不装驱动时的最优选择；
- "vk"：仅发送虚拟键码（最旧的行为），个别老软件不识别扫描码时使用。
手动修改 config.json 后重启程序即可生效；之后点击"保存配置"会保留当前模式。

【十一、DualSense Edge 背键映射（PADDLE_L / PADDLE_R）】
背键是 DSE 背面两个可编程按键。重要事实：XInput 只有 14 个标准按钮，
背键在 Xbox/自动 输入源下不会产生任何事件；只有在 DirectInput 源下
背键才可能暴露为独立按钮位（位号 >= 14）。

绑定方法（一步完成，无需先在列表中选中背键）：
  1. 点击"捕获手柄按键"——程序会自动切换到 DirectInput 源
     （提示文案会说明"已自动切换到 DirectInput 源"）
  2. 按下物理背键（先左后右）
  3. 程序自动把该背键绑定到第一个未绑定的背键条目，并提示
     "已绑定 背键L -> DirectInput 按钮位 N"
  4. 选择键盘按键，点击"设置映射"，再点"保存配置"持久化
之后按背键即等于按映射的键盘键，进游戏由注入模式决定能否被识别。

如果按下背键没有任何反应：
  - 说明该背键在 DirectInput 层不发送事件（DSE 固件默认行为）。
    解法：先用 Sony 官方的 PlayStation Accessories 应用（PC 版）
    把背键映射到某个标准按键（如 ○/✕/□/△），之后本程序就能
    像读普通键一样读到它（此时它等同于被映射到的那个键）。
  - 也可以用命令行诊断实测：双击运行无效，请用命令行执行
      手柄映射器.exe --diag-buttons 30
    依次按含背键在内的所有键，日志（%TEMP%\gm_diag_log.txt）会打印
    设备按钮总数(caps)与每个按下的按钮位号。若 caps buttons >= 16
    而按背键无输出，即确认固件层拦截，需按上述方法先做固件映射。

非捕获模式下，只要检测到"未识别按钮位"（背键候选）且背键未绑定，
程序也会主动在提示区给出绑定指引。
